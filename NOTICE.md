# Attribution and license boundary

This repository documents a file-based adapter between the public InkOS export
format and a PrintFilm import shape. It does **not** copy either upstream
application or bundle their source code.

- InkOS: [`Narcooo/inkos`](https://github.com/Narcooo/inkos), observed as
  **AGPL-3.0** on 2026-10-21. The adapter consumes a user-provided export file.
- PrintFilm: the upstream URL cited by the original project is
  [`yuanzhongqiao/printfilm`](https://github.com/yuanzhongqiao/printfilm), which
  was not publicly resolvable during this audit. Its license and current source
  state are therefore **not verified** here.

The original bridge code and the DevAngular333 smoke path are kept in this
repository. Do not redistribute PrintFilm code or assets without verifying its
license and obtaining any required permission.
